# 4's Problem 랜덤 숫자 뽑기

수업 시간에 사용할 수 있는 간단한 웹 앱입니다.

## 기능
- 0~50 랜덤 문제 뽑기
- 타이머 종료 후 정답 보기 버튼 활성화
- 4's Problem 정답식 표시
- 학생 추가 및 정답 처리(점수 반영)
- 수동 점수 조정(+/- 버튼으로 임의 가감)
- 난이도(★~★★★) 기반 가중 점수
- 실시간 순위(상위 1~3등 + 전체 순위)
- **저장 기능**: 학생 목록/점수/타이머 설정이 브라우저 `localStorage`에 자동 저장됨
- **초기화 버튼**: `초기화` 버튼으로 저장 데이터와 현재 진행 상태를 한 번에 리셋

## 저장(유지) 방식
- 자동 저장 대상
  - 학생 목록과 점수
  - 타이머(초) 설정값
  - 수동 점수 단위 값
- 저장 위치
  - 현재 브라우저의 로컬 저장소(`localStorage`)
- 참고
  - 같은 브라우저/같은 PC에서 새로고침 후에도 유지됩니다.
  - 브라우저 저장소를 지우면 초기화됩니다.

## 실행 방법
### 방법 1) Python으로 실행 (권장)
```bash
cd /workspace/Practice
python3 -m http.server 4173
```
브라우저에서 아래 주소 열기:
- `http://localhost:4173/index.html`

### 방법 2) 파일 직접 열기
- `index.html` 더블클릭으로 바로 실행할 수도 있습니다.
- 다만 일부 환경에서는 보안 정책 때문에 HTTP 서버 실행 방식(방법 1)이 더 안정적입니다.

## 파일 구성
- `index.html`: 화면 구조
- `styles.css`: 스타일
- `script.js`: 로직(랜덤 뽑기/타이머/정답/점수/순위/저장)
