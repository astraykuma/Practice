# 동위각·엇각 시각화 훈련기

중학교 1학년 학생이 동위각/엇각의 "모양 암기"에서 벗어나도록 만든 웹 앱입니다.

## 핵심 설계
- 랜덤 도형 생성: 평행/비평행처럼 보이는 다양한 배치를 자동 생성
- 핵심 3선분 강조: `핵심 선분 강조` 버튼 클릭 시 관련 없는 선분은 옅은 점선 처리
- 문제 풀이: 빨간 기준 각과 동위각 또는 엇각인 번호를 선택해 채점
- 정답 확인: 오답 시 다시 시도, 필요 시 정답 공개 가능

## 학습 메시지
- 동위각/엇각 **정의 자체는 평행 여부와 무관**
- 두 각의 **크기가 같다는 결론은 평행 조건에서만 성립**

## 실행
```bash
cd /workspace/Practice
python3 -m http.server 4173
```
브라우저: `http://localhost:4173/index.html`
